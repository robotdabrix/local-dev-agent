# Local Dev Agent

> A development workspace that helps you move from idea to working software.

## The Opportunity

A local development assistant for understanding a codebase, planning changes, and carrying out project work while keeping the developer in control.

## Who It Serves

Software developers, technical learners, and teams who want a more capable project workspace.

## What It Makes Possible

- Understand a project before proposing changes
- Support code, documentation, and development workflows
- Keep people in control through scoped, reviewable assistance

## How People Use It

1. Open a project in the development workspace.
2. Describe a concrete task and review the proposed approach.
3. Inspect work and choose what to keep.

## How It Connects

- Uses ShareServer for relevant sharing and collaboration workflows. ConnectWBT supports connected accounts and services in supported experiences.
